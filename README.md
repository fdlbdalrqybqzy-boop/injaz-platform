# منصة إنجاز | Injaz

## نبذة عن المشروع

منصة **إنجاز** هي موقع تعريفي احترافي لوكالة برمجة وحلول رقمية تستهدف الشركات والمحلات والمكاتب في عدن واليمن. يقدّم الموقع خدمات تطوير المواقع والأنظمة ولوحات التحكم والأتمتة والتطبيقات المخصصة، ويعرض نماذج من الأعمال والفريق وقنوات التواصل بطريقة عربية متجاوبة مع اتجاه الكتابة من اليمين إلى اليسار.

تعتمد تجربة الموقع على واجهة رئيسية كاملة تعرض جميع الأقسام بالترتيب، إضافة إلى صفحات مستقلة للأقسام الفرعية. المسارات الأساسية هي `/` للرئيسية، و`/about` لمن نحن، و`/services` لخدماتنا، و`/work` لأعمالنا، و`/team` لفريقنا، و`/contact` لتواصل معنا. تحتوي الصفحات الفرعية على القسم الخاص بها ثم التذييل المشترك. في الهاتف تُغلق قائمة التنقل تلقائياً عند اختيار رابط، ويعاد تمرير الصفحة إلى أعلاها.

## الوظائف الأساسية

يحتوي الموقع على Hero داكن بطابع تقني يعرض رسالة إنجاز وإحصائياتها وأزرار الدعوة إلى الإجراء. كما يحتوي على أقسام «من نحن» و«خدماتنا» و«أعمالنا» مع تبويبات تصفية للمشاريع، وقسم «فريقنا»، ونموذج «تواصل معنا» بترتيب RTL وحقول تحقق أساسية. يوفّر الموقع أزرار WhatsApp مباشرة إلى الرقم `+967 775 882 916`، وزراً عائماً بنبض بصري، وروابط البريد والهاتف والشبكات الاجتماعية.

## المتطلبات المسبقة

يُنصح باستخدام **Node.js 20 أو أحدث** و**pnpm 10 أو أحدث**. يمكن تشغيل المشروع من خلال VS Code أو Antigravity IDE أو أي محرر يدعم الطرفية. لا تُضمّن حزمة التحميل مجلد `node_modules`؛ لذلك يجب تثبيت الاعتماديات بعد فك الضغط.

## التشغيل خطوة بخطوة في VS Code أو Antigravity IDE

1. فك ضغط ملف المشروع ثم افتح المجلد `injaz-platform` من خلال **File → Open Folder**.
2. افتح الطرفية المدمجة من **Terminal → New Terminal**.
3. تأكد من وجود Node.js وpnpm عبر الأمرين التاليين:

```bash
node --version
pnpm --version
```

4. ثبّت الاعتماديات:

```bash
pnpm install
```

5. شغّل خادم التطوير:

```bash
pnpm dev
```

6. افتح الرابط الذي يظهر في الطرفية، وغالباً يكون `http://localhost:3000`.
7. عدّل ملفات `client/src`، وسيعيد Vite تحميل التغييرات تلقائياً في المتصفح.
8. جرّب المسارات `/` و`/about` و`/services` و`/work` و`/team` و`/contact` للتحقق من التنقل.

## الفحص والبناء للإنتاج

للتأكد من سلامة أنواع TypeScript شغّل:

```bash
pnpm check
```

لبناء نسخة الإنتاج شغّل:

```bash
pnpm build
```

لمعاينة نسخة الإنتاج محلياً بعد البناء شغّل:

```bash
pnpm preview
```

يمكن تشغيل الخادم الناتج بعد البناء عبر:

```bash
pnpm start
```

## تعديل المحتوى والهوية

توجد معظم بيانات النصوص والمشاريع وروابط التواصل داخل `client/src/pages/Home.tsx`. توجد قواعد التصميم العامة والحركات والثيمات داخل `client/src/index.css`. عند إضافة صورة جديدة، يجب وضع الأصل خارج مجلد المشروع ثم رفعه إلى التخزين المخصص للمشروع، واستخدام رابط التخزين الناتج بدلاً من تضمين ملفات صور كبيرة داخل `client/public`.

رقم WhatsApp المعتمد في المشروع هو `967775882916`، ويُستخدم في رابط المحادثة المباشرة `https://wa.me/967775882916`. عند تحديث روابط الشبكات الاجتماعية، يُفضّل استخدام `target="_blank"` مع `rel="noreferrer"` للروابط الخارجية.

## إرشادات التطوير

ينبغي الحفاظ على اتجاه `dir="rtl"` للنصوص العربية، واستخدام عناصر `bdi` أو `dir="ltr"` للأرقام والبريد وروابط الاتصال حتى لا يحدث تداخل بصري. يجب اختبار التغييرات على عرض مكتبي وعرض هاتف، والتأكد من وجود حالات focus واضحة للعناصر القابلة للنقر. كما يجب تفضيل التعليقات العربية الموجودة في ملفات المصدر عند توسيع المنطق أو تعديل مسؤولية أي مكون.

## الترخيص

المشروع مرخص وفق ملف `package.json` تحت رخصة MIT ما لم تُطبّق حقوق إضافية على الأصول البصرية أو العلامة التجارية. يجب التأكد من ملكية أو ترخيص أي أصل بصري جديد قبل استخدامه في النسخة المنشورة.
